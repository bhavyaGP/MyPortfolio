Coding evaluation architecture

  • Sandboxed runs

    Student code runs in a self-hosted CodeBox sandbox, with time and memory limits on every run.

  • Weighted tests

    Each question has sample and hidden test cases with weights. Hidden details are redacted from stored results.

  • Reports without scores

    An LLM writes feedback on the code, but the score always comes from the tests.

  • Teacher in the loop

    Auto-evaluation creates drafts. Students see a result only after the teacher confirms it.
